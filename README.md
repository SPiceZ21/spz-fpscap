# spz-fpscap
> FPS capping utility for clients

## Scripts

| Side   | File              | Purpose                                               |
| ------ | ----------------- | ----------------------------------------------------- |
| Shared | `config.lua`      | FPS cap configuration                                 |
| Client | `client/main.lua` | FPS cap enforcement logic                             |

## Dependencies
- ox_lib
- spz-core

## CI
Built and released via `.github/workflows/release.yml` on push to `main`.
